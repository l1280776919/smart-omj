## 继续迁移：固定间隔周期任务

任务页可显式勾选周期重复，设置成功结束后的等待间隔（1–10080分钟）和总执行次数（2–100，含首次）。默认仍是一次性任务。每次执行继续使用原配置快照及已有自适应识别策略，并受轮数、总时长、阶段超时限制。

周期采用固定延迟：仅成功结束后，以结束时间加间隔计算下一次，不按旧预约时间补跑；达到总次数后完成。失败、停止或崩溃中断不会重试该周期任务；失败或停止同时暂停队列。暂停期间当前任务成功完成会记录下一次预约，但不会自行启用队列。关闭应用不会唤醒执行，重启后仍须显式启用。过期的pending任务最多先执行一次，再从完成时间计算下一次。

记录增加repeat、completed_runs、last_run，保留最近一次执行结果、轮数、结束时间和运行ID。旧文件缺省字段自动读取为单次任务，不改变已保存任务的行为。下次时间使用溢出检查，累计次数与间隔同时在IPC和加载文件时校验。运行结果必须匹配当前记录的run_id，拒绝重复回调或错配结果。

本轮5项新增测试覆盖结束时间计算、次数上限、失败/停止不重复、暂停不被完成事件恢复、重复/错配结果、旧格式兼容与时间溢出。10项调度测试、9项前端测试及生产构建通过。原生窗口周期运行、真实游戏及跨休眠行为尚未人工验收；不支持按星期/每日时刻等日历规则或系统唤醒。
