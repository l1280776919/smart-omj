# 御魂单人循环规格（实验版）

## 范围与来源

参考上游 Orochi.run_alone 和 GeneralBattle；仅固定 10–13 层、单人、预设阵容。目标是一个有界流程，不覆盖组队、邀请、配队、御魂切换、自动导航、Buff、宠物奖励或自动购买体力。

用户手动进入指定御魂层的单人挑战页，开启锁定阵容和游戏自动战斗。引擎自适应截图尺寸、方向和有效区域，再验证层标题、锁图标和挑战按钮。当前层未命中或阵容未锁定时直接失败。

## 状态

| 状态 | 正向条件 | 动作 | 退出条件 |
| --- | --- | --- | --- |
| 准备 | 目标层、锁定、挑战同时命中 | 点击挑战中心一次 | 缺少前置条件立即失败 |
| 进入战斗 | ready 或 battle 命中 | ready 命中才点击准备；battle 转等待 | 最多 3 次准备操作；阶段超时停止 |
| 战斗等待 | victory 命中 | 点击结算侧边安全区 | defeat 在任何状态命中都失败；阶段超时停止 |
| 胜利 | reward 命中 | 点击结算侧边安全区 | 未确认奖励时等待，超时停止 |
| 奖励 | 目标层标题和挑战重新命中 | 记一轮完成 | 奖励仍存在最多点击 3 次，超时停止 |
| 返回 | 达到轮数则结束，否则重新检查前置条件 | 下一轮 | 总时长达到即停止，结束时不额外点击 |

结算基准坐标 (1175,350) 会经自适应变换映射回真实屏幕，基准位置位于上游 C_WIN_3 / C_REWARD_3 区域交集。体力消耗动作不做盲目重试。必须经过 battle→victory→reward→目标层返回才累计成功轮数。

未知界面不发送动作，等待阶段超时后报告可能体力不足/页面异常/网络故障；没有 OCR，因此当前不能专门识别“体力不足”文字。达到时长可能在战斗中直接停止后续操作，游戏自身可继续自动战斗。

## 自动验证

- 纯状态机：完整一轮、错误层、未锁定、失败、准备重试上限；挑战按钮残留不得重复消耗体力。
- 模板：11 个上游资源加载，在合成 1280×720 画布上精确定位；低纹理、损坏 PNG、多分辨率回映射和取消拒绝。
- 这些是软件单元验证，**不代表游戏兼容或识别回归验收**。本次没有真实游戏截图样本。
